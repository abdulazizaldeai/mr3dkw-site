MR.3D KW - طريقة إضافة منتج جديد

1) حط صور المنتج داخل نفس فولدر الموقع.
   الأفضل تسمية الصور الجديدة بهذا الشكل:
   img_076.jpg
   img_077.jpg
   img_078.jpg

2) افتح ملف index.html.

3) دور على منطقة:
   const PRODUCTS = [

4) انسخ هذا المثال وحطه قبل علامة ]; الأخيرة:

  {cat:'xbloom', name:'اسم المنتج بالعربي', en:'English Name', price:4, images:['img_076.jpg','img_077.jpg'], badge:'xbloom'},

ملاحظات:
- cat ممكن تكون xbloom أو accessories.
- price بدون د.ك، اكتب الرقم فقط.
- images حط أسماء الصور بنفس الاسم الموجود بالفولدر.
- إذا عندك صورة واحدة فقط: images:['img_076.jpg']

تم تعديل السلة:
- عند إضافة منتج، السلة تحدث مباشرة.
- إذا نفس المنتج ونفس اللون انضاف مرة ثانية، تزيد الكمية بدل ما يتكرر.
- السلة تنحفظ مؤقتاً حتى لو العميل حدّث الصفحة.
